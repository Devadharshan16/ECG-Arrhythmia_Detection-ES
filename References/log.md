----------------------------------------------Phase-1 v3 Diagnosis Fixes Start here------------------------------------------
32. Fixed `ecg_dataset.py` — switched from per-window min-max normalization to per-record z-score normalization. Per-window normalization was erasing genuine amplitude differences between normal and anomalous beats (e.g., PVCs are taller/wider). Now computes mean/std once per patient record and applies to all windows from that record.
33. Fixed `train_model_qat.py` — added patient-independent validation split (5 patients: 109, 114, 207, 220, 223 held out from DS1 training). Now tracks val accuracy, sensitivity, specificity, F1 every epoch. Saves best checkpoint by val sensitivity (the most critical clinical metric for anomaly detection).
34. Fixed `train_model_qat.py` — Focal Loss alpha is now computed from actual DS1 training class counts (`n_normal / (n_normal + n_anomaly)`) instead of being hardcoded to 0.50. This directly targets the weak sensitivity (67.5%) by properly weighting the minority anomaly class.
35. Fixed `train_model_qat.py` — removed `torch.clamp(-1, 1)` from data augmentation. With z-score normalization, data is no longer bounded to [-1, 1], so clamping was destroying the amplitude information that the normalization fix preserved. Amplitude scaling augmentation is now truly effective.
36. Saved model diagnosis document as `References/ECG_Model_Diagnosis.md` listing all 4 identified problems and their fixes.
37. Fixed `train_model_qat.py` — dampened Focal Loss alpha (raw 0.8783 → dampened 0.6892) by blending with 0.5 to avoid over-predicting anomalies. Changed best checkpoint selection from pure val sensitivity to val F1-Score, which balances catching anomalies vs. false alarms. First v3 run used pure sensitivity selection and undampened alpha, which caused 12,426 false alarms and dropped accuracy to 74.31%.
